# 바람 공식 배포 사이트

`https://baram.sionyuel.com`에 배포하는 정적 사이트 원본입니다. 공개 프리릴리스 다운로드와 Apple 서명·공증 상태를 함께 표시합니다.

기존 앱 저장소에는 웹 프레임워크가 없어 HTML·CSS·JavaScript로 작성했습니다. npm 의존성은 없습니다.

## 만들고 확인하기

```sh
node site/baram/build.mjs
node site/baram/verify.mjs
python3 -m http.server 8765 --bind 127.0.0.1 --directory site/baram/dist
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. `dist/`는 Cloudflare Worker의 정적 자산으로 배포됩니다.

## 구성

- `src/index.html`: 한국어 우선 제품 소개, 입력 방식 비교와 예시, 지원 세벌식의 양방향 자동 한영 전환·도메인 복원·삭제 경계, 키/Shift 반응 미리보기, 방향별 1.8초 HUD, 권한·Debug 진단 안내, 설치·복구, 배포 상태, 계보·라이선스.
- `src/styles.css`: 저장소 브랜드 팔레트와 macOS 한글 서체를 따르는 반응형 스타일.
- `src/app.js`: 미리 정한 키 순서의 설명용 예시와 시스템/라이트/다크 테마 전환. 키보드 이벤트·문서 내용·사용 기록을 수집하지 않습니다.
- `build.mjs`: 세 파일과 정식 브랜드 토큰·원본 마크를 `dist/`로 복사하고 공개 robots 파일을 만듭니다.
- `verify.mjs`: 앵커·로컬 자산·체크섬·프리릴리스 경고·다운로드 경로와 접근성 기본 규칙을 검사합니다.
- `version.example.json`: 앱이 읽는 안정 업데이트 피드의 스키마 예시. 검증된 릴리스가 생길 때만 `version.json`으로 배포합니다.

- `review/`: 로컬 브라우저 검증 이미지와 결과.

Baram의 공개 버전은 Gureum에서 이어진 번들 버전보다 단조 증가하도록 `2.0.0`부터 시작하며 태그는 `Baram-2.0.0` 형식을 사용합니다. 업데이트 피드는 현재 설치 버전보다 큰 안정 버전만 안내합니다. 예시 피드의 릴리스 링크도 같은 태그 형식을 사용해야 합니다.

브랜드 원본은 `docs/brand/baram`과 `DESIGN.md`입니다. 이 사이트의 `assets`는 빌드 때 복사한 스냅샷이므로 로고·색을 직접 수정하지 않습니다. Apple 글꼴은 배포하지 않고 사용자 시스템의 글꼴을 사용합니다.

## 정식 2.0.0 전에 바꿀 것

1. 정식 이름·자산 라이선스·역사적 프로젝트 관계 표시를 확정합니다.
2. Developer ID·Apple 공증과 실제 Mac/권한/앱 입력·복구 검증을 완료합니다.
3. 적용된 Baram 앱·아이콘·입력 소스 식별자와 설치 경로·옵션 문구·지원 범위를 최종 패키지에서 다시 확인합니다.
4. 검증된 버전, 서명·공증 상태, SHA-256, 릴리스 노트, 대응 소스를 동일 배포물에 연결합니다.
5. 정식 릴리스의 다운로드·업데이트 피드와 실제 도메인·호스팅을 다시 검사합니다.

현재 문구는 프리릴리스의 서명 없음과 물리적 모아치기 실기 미검증을 공개적으로 드러냅니다. 자동 테스트 통과를 모든 앱 호환성이나 일상용 준비 완료로 표현하지 않습니다.
