자동 한영 전환

로마자 모드에서 dkssud → 안녕(두벌식), jfshea → 안녕(세벌식)으로 바꾸고, githubjcnt는 github에서처럼 영문 접두어를 지켜 줍니다. 한글 모드에서 잘못 친 apple, 므너두 → github, 멍젠졍 → tailscale을 영문으로 복원합니다. haezoom처럼 도메인형 키열은 .에서 바로 로마자로 전환해 com을 이어 입력할 수 있습니다.

Control+Command+L로 현재 단어를 영문 용어로 학습하고, Backspace 되돌리기로 한글 유지 선택을 기억합니다. 학습 내용은 이 Mac에만 최대 200개씩 저장되며 설정에서 삭제할 수 있습니다. 현대 두벌식과 지원 세벌식에 적용하며 두벌식 옛글은 제외합니다. 숫자·반복 자모는 그대로 두고 Apple ABC에서는 자동 전환하지 않습니다.

입력 상태를 바로 확인

키와 전환 방향이 보이는 피드백

설정의 자판 미리보기는 설정 창이 보이는 동안 다른 앱에서 누른 키도 강조하고 Shift 윗글자를 표시합니다. 자동 전환에 성공하면 한글은 비취색, 영문은 갈색 알약 알림으로 전환 방향과 ⌫ 되돌리기를 기본 1.8초 보여 줍니다.

현재 음절은 자모 단위로, 앞에서 완성한 음절은 한 글자 단위로 지웁니다. 알림은 등장·취소·교체·종료가 현재 위치와 투명도에서 이어지고 동작 줄이기를 따릅니다.

권한과 개인정보

입력은 내 Mac에서.
관찰은 필요한 순간에만.

일반 입력과 자동 순서 교정에는 키 관찰 권한이 필요하지 않습니다. 입력 모니터링은 지원 세벌식 전용 물리적 동시입력과 오른쪽 키 전환에만 사용합니다.

01

사용자가 직접 허용합니다

세벌식 물리적 동시입력 옵션을 켠 뒤 설정의 ‘허용…’ 버튼을 눌러 macOS 입력 모니터링을 승인합니다. 설치만으로 권한이 자동 승인되지는 않습니다.

02

키 해제만 수동으로 관찰합니다

관찰 탭은 키를 차단·변경·재전송하지 않습니다. 글자 조합과 입력은 InputMethodKit이 담당하며, 입력 소스를 떠나면 관찰도 종료합니다.

03

보안 입력에서는 일반 입력으로

Secure Event Input, 권한 회수 또는 관찰 장애가 감지되면 대기 입력을 원래 순서로 전달하고 일반 입력으로 복귀합니다.

공개 프리릴리스 안내

Release 구성은 입력 내용과 조합 문자열을 진단 로그에 기록하지 않습니다. 자동 한영 전환과 세벌식 물리적 동시입력은 아직 실험 기능이며, 민감한 작업에서는 안정적인 입력 소스로 먼저 전환하세요.

처음 만나는 바람

설치부터 되돌리기까지,
기존 입력기는 곁에 둡니다.

공개 프리릴리스는 직접 설치하는 Universal 앱입니다. 기존 입력기를 지우지 않은 상태에서 시험하세요.

1

파일과 체크섬 확인

GitHub Release에서 ZIP과 SHA-256 파일을 함께 받고 체크섬을 대조합니다. 이 버전은 ad-hoc 서명이며 Apple 공증이 없습니다.

2

사용자 입력기 폴더에 설치

압축을 푼 Baram.app을 사용자 입력기 폴더에 복사합니다. 기존 Baram이 있다면 먼저 별도 폴더에 백업합니다.

~/Library/Input Methods/Baram.app
3

익숙한 배열을 선택

시스템 설정 → 키보드 → 텍스트 입력에서 원하는 바람 세벌식 배열을 추가합니다. 기존 Lab의 배열 선택과 단축키는 새 설정 저장소로 한 번 복사됩니다.

4

문제가 생기면 바로 복귀

ABC·기존 한글·구름으로 전환합니다. Baram 제거와 백업은 다른 입력기와 저장 설정을 건드리지 않습니다.

입력 소스 목록에 보이지 않으면?

시스템 설정에서 입력 소스를 다시 확인하고, 새 입력기가 반영되지 않았다면 작업을 저장한 뒤 로그아웃·로그인을 진행합니다. 기존 입력기는 먼저 지우지 마세요.

macOS가 실행을 차단하면?

이 프리릴리스는 Developer ID 서명·Apple 공증을 받지 않았습니다. ZIP의 SHA-256을 먼저 확인한 뒤 앱을 한 번 열고, 시스템 설정 → 개인정보 보호 및 보안에서 ‘확인 없이 열기’를 선택하세요. 보안 기능 전체를 끄거나 격리 속성을 강제로 제거하지 마세요. Apple의 안전한 앱 열기 안내

이어온 것과 새로 만드는 것

구름에서 출발한,
독립적인 바람.

바람 입력기는 구름 입력기를 기반으로 새롭게 개발하는 독립 오픈소스 프로젝트입니다. 한글 조합은 libhangul의 작업 위에 놓여 있습니다.

과거의 한글입력기 바람과 구름 입력기가 남긴 한글 입력 환경의 발자취를 존중합니다. 과거 바람의 공식 후속판 또는 개발자 승인을 뜻하지 않습니다.

소스·의존성·자산의 라이선스는 서로 다를 수 있습니다. 정식 배포물에는 해당 고지와 필요한 소스를 함께 제공합니다.

소스와 라이선스 확인 ↗

시험 버전에서 이전 버전으로

먼저 ABC나 기존 한글 입력기로 전환합니다. 설치기가 보존한 ~/Library/Application Support/Baram/Backups/에서 복구할 앱을 고르고, 번들 식별자와 서명을 확인한 뒤 현재 Baram도 백업으로 보존합니다. 선택한 백업을 사용자 입력기 폴더에 복사하고 재등록합니다.
