# Baram 1.0.0-rc.3

자동 한영 전환의 실제 사용 오탐과 설정 자판 미리보기의 입력 연결을 다듬은 세 번째 프리릴리스입니다.

## 주요 변경

- 세벌식 최종에서 `므너두 → github`를 시스템 영문 사전과 무관하게 복원
- 두벌식 `githubdptj → github에서`, 세벌식 최종 `githubjcnt → github에서` 안정화
- `;vies → 보면`처럼 선행 문장부호를 버렸을 때만 영단어가 되는 키열의 오탐 방지
- `hello;`, 따옴표·괄호로 감싼 영단어, 기존 영단어·도메인 복원 유지
- 설정의 현재 한글 자판이 다른 앱에서 누른 키와 Shift에도 반응
- 설정 창을 닫았다 다시 열어도 미리보기 관찰 유지
- 보안 입력 중에는 미리보기 이벤트를 전달하지 않으며 키 해제 이벤트를 소비하지 않음

## 배포 상태

- Release 구성, macOS 12 이상
- `arm64`와 `x86_64`를 포함한 Universal 앱
- ad-hoc 코드 서명
- Developer ID 서명과 Apple 공증 없음
- 자동 업데이트 비활성
- 자동 한영 전환과 물리적 동시입력은 기본 꺼짐인 실험 기능

macOS가 앱을 차단하면 ZIP의 SHA-256을 확인한 뒤 앱을 한 번 열고 `시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기`를 사용하세요. 보안 기능 전체를 끄거나 격리 속성을 제거하지 마세요.

## 검증

- 전체 macOS 단위 테스트 269개
- 자동 한영 전환 회귀 테스트 77개
- 설정 화면 테스트 21개
- GitHub Actions build/test, Baram Release 계약, ShellCheck, Swift format
- Universal 아키텍처, 번들 identity, 코드 서명, 패키지 체크섬 검증

## 알려진 제한

- Apple 개발자 등록 전이라 Gatekeeper가 기본 실행을 차단합니다.
- 자동 전환은 사전과 입력 형태를 함께 사용하는 휴리스틱이므로 모든 고유명사와 혼합어를 알지는 못합니다.
- 실제 앱의 조합 문자열 처리에 따라 자동 전환 동작이 다를 수 있습니다.
- 문제가 생기면 ABC나 기존 한글 입력기로 전환하고, 기존 입력기는 제거하지 마세요.
- 자동 업데이트는 정식 서명·공증 릴리스 전까지 동작하지 않습니다.

보안 문제는 공개 이슈 대신 [비공개 보안 권고](https://github.com/sionyuel/baram/security/advisories/new)로 알려 주세요.
