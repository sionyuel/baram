# Baram 1.0.0-rc.9

사용자의 선택을 Mac 안에서 기억하는 개인 교정 학습을 추가한 아홉 번째 프리릴리스입니다.

## 주요 변경

- 밑줄로 조합 중인 단어에서 `Control+Command+L`을 눌러 영문 용어 학습
- `므너두에서 → github에서`처럼 알려진 영문 접두어와 한글 조사 교정
- 학습한 전체 영문 단어와 혼합 단어를 다음 입력부터 자동 적용
- 자동변환 직후 Backspace 취소를 자판별 한글 유지 예외로 학습
- 완성형 한글 `쪽`, `걱`을 약한 시스템 사전의 `llvx`, `ktx`보다 우선
- 보안 입력·제외 앱·소유하지 않은 marked range에서는 학습하지 않음
- 학습 단어와 한글 유지 예외를 각각 최대 200개까지 로컬 저장
- 고급 설정에서 항목 개별 삭제와 전체 초기화

## 개인정보

- 현재 입력기가 소유한 물리 키열과 학습 결과만 Baram defaults에 저장
- 앞 문장이나 이미 확정된 문서를 읽지 않음
- 학습 데이터 네트워크 전송·동기화 없음

## 검증

- 전체 macOS 단위 테스트 299개
- 자동 한영 전환·학습 회귀 테스트 107개
- 실제 Control→Command→L 이벤트 순서, 커서 이동 거부, 혼합 교정 undo, 저장 한도 검증
- Universal Release 계약, Swift format, 사이트 검증

Developer ID 서명·Apple 공증과 자동 업데이트는 아직 적용하지 않았습니다.
