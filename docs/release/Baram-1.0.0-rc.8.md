# Baram 1.0.0-rc.8

전화번호처럼 앱이 자체 포맷하는 숫자 필드와 자동전환 버퍼가 충돌하던 문제를 수정한 여덟 번째 프리릴리스입니다.

## 주요 변경

- 한글 자판 결과에 한글이 전혀 없으면 첫 글자에서 자동전환 marked-text 버퍼 종료
- 전화번호·인증번호·숫자 입력을 즉시 확정해 앱의 자동 하이픈·커서 이동에 소유권 양보
- 세벌식 숫자 입력 뒤 marked range가 남지 않는 회귀 테스트 추가
- 한글 조합에 숫자 키를 사용하는 정상 세벌식 단어와 RC7 기능 유지

## 검증

- 전체 macOS 단위 테스트 290개
- 숫자 즉시 확정, 반복 자모, 세벌식 숫자 키 조합 회귀
- Universal Release 계약, Swift format, 사이트 검증

Developer ID 서명·Apple 공증과 자동 업데이트는 아직 적용하지 않았습니다.
