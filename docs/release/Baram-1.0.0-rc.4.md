# Baram 1.0.0-rc.4

자동 한영 전환을 사용자가 즉시 되돌릴 수 있도록 만든 네 번째 프리릴리스입니다.

## 주요 변경

- 자동 전환 직후 첫 Backspace로 변환 전 단어와 이전 내부 입력 모드 복원
- 공백·Return·Tab 경계는 유지하고 두 번째 Backspace부터 일반 삭제
- 다른 키 입력, 커서 이동, 클라이언트 변경, 외부 커밋, 보안 입력에서는 취소 기록 폐기
- UTF-16 범위만 기억하며 기존 문서 내용을 읽지 않는 복원 경로
- 토스트에 `⌫ 되돌리기` 안내를 표시하고 취소하면 즉시 닫기
- 빠른 취소 뒤 예약된 토스트가 다시 나타나지 않도록 표시·닫기 순서 보장
- 다른 입력 창이 마지막 자판 설정을 바꿔도 정확한 이전 자판 복원

## 배포 상태

- Release 구성, macOS 12 이상
- `arm64`와 `x86_64`를 포함한 Universal 앱
- ad-hoc 코드 서명
- Developer ID 서명과 Apple 공증 없음
- 자동 업데이트 비활성
- 자동 한영 전환과 물리적 동시입력은 기본 꺼짐인 실험 기능

## 검증

- 전체 macOS 단위 테스트 277개
- 자동 한영 전환 회귀 테스트 85개
- 양방향 변환, Space·Return·Tab, UTF-16 앞문장, 보안 입력, 커서·클라이언트 변경 검증
- HUD 예약 경쟁과 입력 모드 부분 전환 회귀 테스트
- GitHub Actions build/test, Baram Release 계약, ShellCheck, Swift format

## 알려진 제한

- Apple 개발자 등록 전이라 Gatekeeper가 기본 실행을 차단합니다.
- 자동 전환은 사전과 입력 형태를 함께 사용하는 휴리스틱이므로 모든 고유명사와 혼합어를 알지는 못합니다.
- 직전 변환 취소는 변환 이후 다른 입력이나 커서 이동이 없을 때만 동작합니다.
- 실제 앱의 조합 문자열 처리에 따라 자동 전환과 취소 동작이 다를 수 있습니다.
- 자동 업데이트는 정식 서명·공증 릴리스 전까지 동작하지 않습니다.

보안 문제는 공개 이슈 대신 [비공개 보안 권고](https://github.com/sionyuel/baram/security/advisories/new)로 알려 주세요.
