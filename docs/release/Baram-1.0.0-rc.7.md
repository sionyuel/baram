# Baram 1.0.0-rc.7

반복 한글 자모 뒤에 문장부호가 붙은 경우까지 한글로 보존하는 일곱 번째 프리릴리스입니다.

## 주요 변경

- `ㅎㅎㅎㅎ.`, `ㅋㅋㅋㅋ.`, `ㅠㅠ!`처럼 반복 자모 뒤에 붙은 문장부호를 제외하고 본문을 판정
- 마침표 뒤 공백에서 `mmmm.`·`0000.`으로 뒤늦게 역변환되던 RC6 누락 수정
- RC6의 반복 자모 공백 보존과 RC5 기능 유지

## 검증

- 전체 macOS 단위 테스트 290개
- `mmmm`, `0000`, `mmmm.`, `0000.` 확정 회귀
- Universal Release 계약, Swift format, 사이트 검증

Developer ID 서명·Apple 공증과 자동 업데이트는 아직 적용하지 않았습니다.
