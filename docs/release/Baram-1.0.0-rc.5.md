# Baram 1.0.0-rc.5

도메인 입력 흐름, 기술용어 판정, 숫자 보존과 자동전환 토스트 종료를 다듬은 다섯 번째 프리릴리스입니다.

## 주요 변경

- `haezoom` 같은 도메인형 입력을 `.`에서 즉시 `haezoom.`으로 바꾸고 로마자 모드로 전환
- 영문 모음·자음, 길이, 자모 조건으로 숫자열·자음 반복·`ㅋㅋㅋㅋ.` 오탐 방지
- 작은 내장 기술용어 목록을 중앙화하고 `github`, `tailscale` 지원
- 순수 숫자·기호 출력에는 역변환을 적용하지 않아 세벌식 `5555 → YYYY` 오탐 방지
- 토스트 종료의 투명 상태를 패널이 닫힐 때까지 유지해 마지막 프레임 깜빡임 제거
- 등장 중 즉시 취소하거나 종료 중 새 토스트가 와도 현재 위치·투명도에서 연속 전환
- Reduce Motion의 150 ms 투명도 전환, 기존 스프링·펄스·유지시간 보존

## 배포 상태

- Release 구성, macOS 12 이상
- `arm64`와 `x86_64`를 포함한 Universal 앱
- ad-hoc 코드 서명
- Developer ID 서명과 Apple 공증 없음
- 자동 업데이트 비활성
- 자동 한영 전환과 물리적 동시입력은 기본 꺼짐인 실험 기능

## 검증

- 전체 macOS 단위 테스트 289개
- 자동 한영 전환 회귀 테스트 97개
- 도메인 즉시 전환·취소, 기술용어, 숫자·웃음 입력 보존 회귀
- 정상/Reduce Motion 토스트 종료, 즉시 취소, 종료 중 교체, 펄스·유지시간 회귀
- GitHub Actions build/test, Baram Release 계약, ShellCheck, Swift format

## 알려진 제한

- Apple 개발자 등록 전이라 Gatekeeper가 기본 실행을 차단합니다.
- 내장 기술용어는 실제 실패가 확인된 소수만 포함합니다.
- `.` 즉시 전환은 구조적 휴리스틱이므로 잘못 전환되면 즉시 Backspace로 되돌리세요.
- 특정 편집기의 조합 범위 처리에 따라 자동전환 버퍼가 시작되지 않을 수 있습니다.
- 자동 업데이트는 정식 서명·공증 릴리스 전까지 동작하지 않습니다.

보안 문제는 공개 이슈 대신 [비공개 보안 권고](https://github.com/sionyuel/baram/security/advisories/new)로 알려 주세요.
